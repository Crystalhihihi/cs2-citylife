## 一、当前形态（全部已部署到本地 Mods/CityLife，git 已入库）

**信息层**：自建信息流面板（GameTopLeft 气泡按钮）——LLM 批量帖（人格卡×形态×真实业态锚点）+ 评论区（神评/抬杠/共情分工）+ 板块 tab（综合/突发/热帖/连载）+ 市长发帖框 + 回复 + 拖拽缩放 + 自绘滚动条。原版 Chirper 被发布侧 Harmony 补丁根治（实体级删除）。

**写回层（M4 活动链，本次重点验收对象）**：
市长发帖说办活动 → 意图解析（LLM 归一化 startHour/durationH/scale/budget）→ **原生弹窗确认（候选全量公园真名 + 地图选点任意建筑 + 时段警示）** → 真扣财政（时长平方级加价）→ 公告 → 下一个整点开场 → 吸引力 ramp + 分批注入 → 实数到场 → 结算（爆棚返 50%/及格 20%/冷场骂）→ 参数恢复。阴间时段（0-6 点）人气系数 0.15 且必挨骂。

**突发层（本轮新增，"大事没人谈论"的根治）**：直采事件组件（火灾=OnFire、车祸/犯罪=AccidentSite.m_Flags，分类学见 `docs/spikes/2026-08-20-event-taxonomy.md`）→ 突发帖（带锚点可"前往现场"）+ 写 `LiveContext.LastBreaking` → 下一炉市民集中议论（热议串）。此前 LastBreaking 全库无人写入，热议炉从未触发。

## 二、验证清单（按序）

1. 重启游戏，日志（`Logs/CityLife.log`）无 CRITICAL、有 `[Filter] 原版 chirp 过滤补丁已应用`
2. 市长发帖："明晚 8 点办个周末市集，预算中档" → 弹窗出现，**候选地点是"方位·真名"且数量随城市公园数**（不再恒 4-5——旧版拿锚点采样池当场馆池，公园上限 4 是根因）
3. **地图选点**：点"在地图上选点"→ 卡片收成提示条 → 点任意建筑（商店/学校/住宅均可）→ 卡片回来显示"地点：XXX（改回列表）"→ 确认后公告/开场/聚集都落在该建筑；选点中 Esc 只退选点不取消卡；"改回列表"可切回候选
4. 确认后日志看 `[Money] 财政 -XXX`（真扣）→ `[Event] 已排期 明晚 20:00` → 到点 `[Event] 开场` + 场馆人群聚集
5. 结算帖：爆棚/及格/冷场 + 下一炉市民议论活动（【活动结果】上下文）
6. **突发热议**（本轮核心）：等城里出火灾/车祸/盗窃（或 developerMode 点火）→ 突发帖出现 + **下一炉市民集中议论此事**（热议串、评论多）——此前 `LiveContext.LastBreaking` 全库无人写入，热议炉从未触发；`[News] 突发（fire/crime/accident）` 日志同步有记录
7. 对照组（可选）：凌晨 3 点办一场——红色"时段阴间"警示，到场惨淡，结算必挨骂
8. 面板交互回归：拖拽/缩放/滚动条/贴底/中文输入不豆腐块；原版 chirp 仍被过滤

## 三、已知待校准项（玩的时候留意日志）

- `[Anchor·校准]`：公司盈利分布（阈值 200/50 是猜的）与业态词命中率——攒半小时日志可校准
- 吸引力 boost +100 是初估值（`EventChainSystem.BeginRunning`），看人群到场速度是否偏弱/过强
- 晚高峰 API 偶发 >240s 尖峰（已调 420s；再超时有日志 `[LLM] 一炉失败`），面板短暂安静属供给侧现象
- `[News] 突发（fire/crime/accident）`：突发事件直采（OnFire/AccidentSite，2026-08-20 分类学实锤）——太频繁就调 `EventNewsSystem` 的 2048/512 帧限流；连环火灾也只发一条后进入冷却
- `[Pick]`：地图选点日志（"选中的不是建筑"/"冷却中"都是正常拒绝，卡片不动）
