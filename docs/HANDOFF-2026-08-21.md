## 三、世界空间渲染·全部实锤与教训（这轮彻查的结晶，勿重探）

**死因链**：`HDRP/Unlit` 不在发布 build 着色器清单 → `Shader.Find` 拿到无效 fallback → GameObject+MeshRenderer、beginCameraRendering+Graphics.DrawMesh、CustomPass+cmd.DrawMesh **三条路全是死材质陪葬**，与接入方式无关。

**正路（社区 20+ mod 验证）**：`Game.Rendering.OverlayRenderSystem`
- 写入：`GetBuffer(out deps)` → `DrawCircle/DrawCustomMesh/DrawText` → `AddBufferWriter(deps)`；
- **注册相位必须 GameSimulation**（Rendering 相位写入被其清/拷时序永久跳过——实例计数全 0 实锤）；
- **`hideOverlay` 闸**：`RenderingSystem.hideOverlay`（公开 get;set;）为 True 时连收都不收——气泡开着期间每帧压 false（渲染层开关，不碰模拟数值）；
- **世界文字**：空实体 + `NameSystem.SetCustomName` → `Buffer.DrawText(entity, pos, cameraFace:true)`（画实体渲染名，写什么画什么；CJK 零风险——游戏自带字体图集）；
- **锚点 y 用实体真实 Transform**（落点打 y=0 平面曾把气泡埋在地下；地形高度不可信）；
- **LOD 用镜头到落点距离**（裸高度不随俯仰角代表远近——实机 542m+ 全灭教训）；
- 相机权威源 = `CameraUpdateSystem.activeCamera`（Camera.main 在部分相位为 null/可能是代理）；
- **DrawText 弃用实锤（2026-08-21 实机截图 + roadmod 反编译逐行对码）**：文字网格由 OverlayRenderSystem 全局共享 TMP 以 fontSize=200 懒烘焙、绘制 matrix scale=1 硬编码 → "区名牌"级巨字；overlay 渲染通道只按曲线/网格计数开门、**文字不计数** → 悬停建筑（游戏自己画框）通道才开 → "悬停才显示/放大没了/俯仰角玄学"。"窗口期改字号"方案证实危险勿回頭：ASL mod 实锤共享 TMP 状态残留会污染全城路名/区名烘焙缓存。
- **v2 正路（NodeController/AllSpeedLimits/RoadSpeedAdjuster 三家 mod 同款，已落地）**：借 `GetTextMesh()` 自烘文字网格（**快照八项状态+finally 恢复**）→ 材质 clone `OverlayConfigurationPrefab.m_TextMaterial`（永不 Shader.Find）+ `CopyFontAtlasParameters` 灌图集 + `_FaceColor` 按类型上色 → `RenderPipelineManager.beginContextRendering` 自绘（billboard + 恒定屏占：世界高=2·dist·tan(fov/2)·目标px/屏高，夹 0.35-5m）。文字缓存 LRU 上限 48。
- **贴图面片备选（底板/边框用）**：通知图标管线——材质 clone `IconConfigurationPrefab.m_Material`（shader=Shader Graphs/NotificationIcon，build 实锤存在）换 `mainTexture`=自建 Texture2DArray；实例布局 `NotificationIconBufferSystem.InstanceData{float3 m_Position; float4 m_Params; float m_Icon; float m_Distance}`(36B)，`m_Params`=(尺寸,脉动,透明度,开关)；`Graphics.DrawMeshInstancedIndirect` + `beginContextRendering`（TLE 先例；它不过 OverlayRenderSystem）；遮挡变浅靠 shader 的 DEPTH_FADE_FROM_TEXTURE。
- 参考实锤：`Quboid/CS2-MoveIt`（Overlays/OverlaySystem.cs 用法原文）、`krzychu124/Traffic`、`kurupted/CS2TransitView`（最简模板）、`slyh/Cities2-TrafficLightsEnhancement`（图标管线复刻）、`bworthy89/roadmod`（游戏系统反编译参考）。
- **RimWorld 对照结论**：RimTalk 气泡也是贴纸（GenMapUI 投影+IMGUI），赢在 RimWorld 把 UI 架在 OnGUI 上送钩子；CS2 无等价钩子，但 CS2 有真 3D 世界 UI（通知图标遮挡变浅实锤）——两码事。
