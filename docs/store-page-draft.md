# CimLife 市民圈 —— 发布页文案草案（内部评审稿）

> 用途：PDX Mods 发布页的中文版底稿。文案口径=玩家视角，只讲体验不讲架构。
> 强承诺句（"真的堵起来""真的会来"）以 M0/M4 spike 通过为前提，翻车则降级为"小规模聚集"措辞。
> 气泡段落是全文技术风险最高的承诺，备选策略：首版页面不写气泡，M3 落地后随版本更新补发。

---

**你的城市不只会运转，它还会生活。**

## 这是什么

市民圈用一个由大语言模型驱动的虚拟社交平台，替换游戏自带的 Chirper。平台上的每一条内容都不是随机套话——它们锚定你城市此刻真实发生的事：刚加的税、堵死的主干道、新开的商业街、昨晚那场雨。

## 一座在议论你的城市

- 市民、商家、政府部门各自发帖：招聘信息、开业宣传、路况吐槽、官方通报
- 评论区有热评、有抬杠、有玩梗，甚至完整的对骂连续剧
- 同城 / 招聘 / 商家 / 吐槽 / 公告 / 热搜，热搜跟着城市事件实时起伏
- 你治理得好，平台主流是真夸；治理得烂，就会被骂上热搜——AI 忠于模拟，不为毒舌而毒舌
- 外地网友和旅游博主也会来围观你的城市：景区帖下面"求地址"，宰客帖下面"幸亏没去"

## 放大城市，听到街头

- 镜头拉近，行人头顶冒出闲聊；堵车时车主在车里骂街；公交站候车的人群聊家常
- 住宅楼议论房租和学区，办公楼吐槽加班，商店议论生意好坏——每栋楼里都有声音

## 你说话，城市当真

- 以市长身份发帖，AI 会把你的话变成真实的游戏事件
- 宣布"明晚八点中央公园烟花节"：官方号发公告，市民分批出发，道路真的堵起来，附近商家真的赚钱，第二天平台上全是昨晚的现场讨论；碰上下雨，就是另一番冷场剧本
- 说"给全市发钱"这种话，会弹出确认框告诉你财政后果；你坚持，后果由游戏引擎真实地模拟给你看
- 你的意图暂时做不到时，城市会告诉你"做不到"，而不是假装执行了

## 有记忆的城市

- 事件当事人会被引用发声；一夜爆红的市民成为网红；持续活跃的网红成为"明星市民"——有人格、有记忆，会连续追踪评论大事件，形成你自己的城市连续剧
- 星标任何市民，亲手把他打造成明星，编辑他的人设
- 明星也会过气——"过气网红复出"本身就是平台上的梗
- 给市民点赞：他会开心，被赞的店会迎来真实客流，明星会记得"市长给我点过赞"

## 经营城市的口碑

- 景区在平台上被夸，外地游客真的会多起来；被吐槽宰客，游客真的会减少
- 酒店和商业营收随口碑真实起伏——旅游第一次变成可以经营的玩法

## 必要前提：一个 LLM 供给

本 mod 的内容由 AI 实时生成——没有 AI 就没有市民圈。二选一：

- 订阅制代码 CLI（首发支持 Kimi Code，社区可适配其他 CLI）：用你已有的订阅，一晚额度内几块钱
- 按 API 计费的 OpenAI 兼容端点（硅基流动 / DeepSeek 官方等）：平民模型一晚约一瓶水钱

MUTE 模式可一键停 AI（信息流静默，零 token 消耗）。

## 使用前你需要

- Cities: Skylines II 本体
- 解锁全部 AI 功能：接入你顺手的 LLM 供给——订阅制代码 CLI（首发支持 Kimi Code，社区可适配其他 CLI）或按 API 计费的接入。mod 的 prompt 按"固定前缀+动态尾部"组织，无论哪种方式都尽量吃满缓存：订阅制省额度，计费制直接省钱
- 本 mod 不收集任何数据；城市状态摘要只经由你自己安装的 CLI 发出

## 性能与掌控

- 为 50 万人口大城市设计：AI 调用全部后台异步，不阻塞模拟；游戏加速时自动降频停 AI
- 写回强度四档：体验（±5% 纯氛围）/ 正常（默认）/ 疯狂（±30%，可能交通瘫痪，有警告）/ 自定义（可完全关闭写回，只留氛围）
- 气泡数量、时长、开关全部可调；打开建造工具时自动隐藏

## 内容安全

- 语气三档：全年龄 / 默认 / 放开骂
- AI 对事不对人：可以骂"这个税加得离谱"，不会攻击你本人，不碰现实议题
- 吐槽商家 / 规划 / 市长可分别关闭，另有硬过滤兜底
- 平台内容均为 AI 虚构生成，与玩家本人无关
